LXC on DSM Lab

Native LXC on DSM is powerful and sharp-edged. This first GUI intentionally acts as a safe control panel: it documents package paths and shows explicit root commands for reviewed lifecycle gates.

Package Center start/stop is intentionally blocked for the package user. Privileged operations require a reviewed root shell command.

Empty-network mode is safest for a persistent first container. macvlan mode performs DHCP only after an explicit --run.

1. Check packaged runtime

Dry-run dependency check. Does not restore files and does not start containers.

sh /var/packages/lxc-on-dsm/target/scripts/install-packaged-runtime.sh

2. Restore runtime

Explicitly restores the packaged LXC runtime under the lab prefix.

sh /var/packages/lxc-on-dsm/target/scripts/install-packaged-runtime.sh --install

3. List package containers

Read-only inventory of package-owned lab containers and their current LXC state.

sh /var/packages/lxc-on-dsm/target/scripts/list-packaged-containers.sh

4. Plan container creation

Shows the target paths for a stopped Alpine container. No files are written.

sh /var/packages/lxc-on-dsm/target/scripts/create-packaged-container.sh --name alpine-lab --network-type none

5. Create stopped container

Creates the container rootfs and config. It does not start the container.

sh /var/packages/lxc-on-dsm/target/scripts/create-packaged-container.sh --name alpine-lab --network-type none --create

6. Start/stop a package container

Starts a package-created lab container and keeps it running until stopped explicitly.

sh /var/packages/lxc-on-dsm/target/scripts/start-packaged-container.sh --name alpine-lab
sh /var/packages/lxc-on-dsm/target/scripts/start-packaged-container.sh --name alpine-lab --run
sh /var/packages/lxc-on-dsm/target/scripts/stop-packaged-container.sh --name alpine-lab

7. Optional container start hook

Installs a dispatcher that runs executable scripts from /etc/lxc-on-dsm/start.d inside the container.

sh /var/packages/lxc-on-dsm/target/scripts/install-packaged-start-hook.sh --name alpine-lab
sh /var/packages/lxc-on-dsm/target/scripts/install-packaged-start-hook.sh --name alpine-lab --install

8. Attach diagnostic

lxc-attach is kept as a diagnostic only; DSM may reject it because of seccomp/capability limitations.

sh /var/packages/lxc-on-dsm/target/scripts/exec-packaged-container.sh --name alpine-lab
sh /var/packages/lxc-on-dsm/target/scripts/exec-packaged-container.sh --name alpine-lab --run -- hostname

9. Smoke-test stopped container

Starts a networkless container once, records evidence, and stops it again.

sh /var/packages/lxc-on-dsm/target/scripts/run-packaged-smoke-test.sh --name alpine-lab

10. Optional macvlan DHCP test

Creates a stopped macvlan container, then runs one temporary DHCP/LAN probe.

sh /var/packages/lxc-on-dsm/target/scripts/create-packaged-container.sh --name alpine-lan --network-type macvlan --parent-if eth0 --create
sh /var/packages/lxc-on-dsm/target/scripts/run-packaged-macvlan-dhcp-test.sh --name alpine-lan
sh /var/packages/lxc-on-dsm/target/scripts/run-packaged-macvlan-dhcp-test.sh --name alpine-lan --run

11. Lifecycle status

Read-only doctor for the configured macvlan profile.

sh /var/packages/lxc-on-dsm/target/scripts/lxc-on-dsm-root-helper.sh status --profile /var/packages/lxc-on-dsm/etc/lab-macvlan.env

12. Start/stop via root helper

Starts or stops only the configured lab container after the profile is reviewed.

sh /var/packages/lxc-on-dsm/target/scripts/lxc-on-dsm-root-helper.sh start --profile /var/packages/lxc-on-dsm/etc/lab-macvlan.env
sh /var/packages/lxc-on-dsm/target/scripts/lxc-on-dsm-root-helper.sh stop --profile /var/packages/lxc-on-dsm/etc/lab-macvlan.env

Current boundaries

  • No automatic runtime restore during package install.
  • No automatic container creation or start during package install.
  • No Entware dependency on the DSM target.
  • No production readiness claim.
